EMA packages this unmodified model inside its APK at build time. EMA's own
wake-word grammar, audio gate, service lifecycle and command execution are
separate application code. Wake detection does not require a separate app,
account, API key, runtime model download, or user-selected ZIP.

The English vocabulary uses "hey emma" for the spoken EMA name. Recognition
accuracy and pronunciation coverage need device testing. The model is not
claimed to be newly trained by EMA or to be a manufacturer DSP sound model.
