EMA packages this unmodified model inside its APK at build time and shares one
verified on-device instance across EMA's offline speech-to-text engine
(EmaOfflineSpeechEngine / EmaRecognitionService) and local "Hey EMA" wake-word
detection. EMA's audio signal conditioning, adaptive voice-activity detection,
continuation-aware endpointing, N-best contextual rescoring, inverse text
normalization, phonetic grounding, wake grammar, service lifecycle and command
execution are separate application code. Offline speech recognition and wake
detection work completely offline without a separate app, account, API key,
runtime model download, or user-selected ZIP.

The English vocabulary uses "hey emma" for the spoken EMA name. Recognition
accuracy and pronunciation coverage need device testing. The model is not
claimed to be newly trained by EMA or to be a manufacturer DSP sound model.
