EMA Windows packages this unmodified model inside its portable application at
build time, alongside the desktop Vosk speech-to-text runtime. Audio is processed
locally without an account, API key or runtime model download. The desktop edition
uses press-to-talk and reviewed transcripts; it does not implement Android wake-word
services, phone integrations or Android's DSP/rescoring pipeline.

The English vocabulary uses "hey emma" for the spoken EMA name. Recognition
accuracy and pronunciation coverage need device testing. The model is not
claimed to be newly trained by EMA or to be a manufacturer DSP sound model.
